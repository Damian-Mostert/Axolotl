# Axolotl IntelliSense

IntelliSense and autocomplete support for Axolotl programming language.

## Features

- Autocomplete for keywords
- Autocomplete for built-in types
- Autocomplete for 80+ built-in functions
- Function suggestions with details

## Installation

```bash
cd axolotl-intelsense
npm install
code --install-extension .
```

## Built-in Functions Included

I/O, arrays, strings, math, conversion, objects, canvas 2D/3D, HTTP, JSON, and more.
