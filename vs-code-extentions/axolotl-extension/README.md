# Axolotl Language Support

Complete VS Code extension for the Axolotl programming language.

## Features

- **Syntax Highlighting** - Full syntax highlighting for `.axo` files
- **IntelliSense** - Autocomplete for keywords, types, and 100+ built-in functions
- **Hover Documentation** - View function signatures and descriptions on hover
- **Code Formatting** - Auto-format your Axolotl code
- **Function Browser** - Browse and insert built-in functions by category

## Usage

### Function Browser
Press `Cmd+Shift+P` and type "Axolotl: Browse Built-in Functions" to browse functions by category:
- Array, String, Conversion, Object
- I/O, Utility, HTTP/JSON
- 2D Canvas, 3D Scene, 3D Lighting, 3D Transform, 3D Graphics
- Physics, Input

### Formatting
Right-click in an `.axo` file and select "Format Document" or use `Shift+Alt+F`.

## Installation

```bash
code --install-extension axolotl-extension-1.0.0.vsix
```
