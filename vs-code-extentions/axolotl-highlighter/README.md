# Axolotl Syntax Highlighter

Syntax highlighting for the Axolotl programming language (.axo files).

## Features

- Syntax highlighting for keywords, types, strings, numbers, comments
- Auto-closing brackets and quotes
- Comment toggling with Ctrl+/

## Installation

```bash
cd axolotl-highlighter
code --install-extension .
```

## Supported

- Keywords: `var`, `const`, `func`, `if`, `else`, `while`, `for`, `return`, `break`, `continue`, `switch`, `case`, `default`, `try`, `catch`, `finally`, `throw`, `import`, `export`, `use`, `type`, `program`, `await`, `typeof`
- Types: `int`, `float`, `string`, `bool`, `void`, `any`, `object`
- Comments: `//`
- Strings with escape sequences
- Numbers (integers and floats)
