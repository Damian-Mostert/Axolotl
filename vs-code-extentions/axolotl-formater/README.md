# Axolotl Formatter

Code formatter for Axolotl programming language.

## Features

- Auto-indent based on braces and brackets
- Format on save (configurable)
- Format selection or entire document

## Installation

```bash
cd axolotl-formater
npm install
code --install-extension .
```

## Usage

- Format document: `Shift+Alt+F` (Windows/Linux) or `Shift+Option+F` (macOS)
- Format on save: Enable in VS Code settings
